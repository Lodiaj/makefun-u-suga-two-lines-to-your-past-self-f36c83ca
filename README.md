Two lines to my past self: a warning about one specific moment, and one sentence on why it mattered.

Line one warns against sending the 2am "project is done" email while the tests are still red. Line two traces the consequence: the boss forwarded it to the client before sunrise, and trust had to be rebuilt one midnight fix at a time.

## Run it

```sh
node main.ts
```

This writes the two lines to `/output/entry.txt` (233 characters, within the 1–280 gate), validating that the text is exactly two lines of one sentence each before writing, and reading the file back to confirm it matches.
